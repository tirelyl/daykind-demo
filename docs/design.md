# Everyday Edit design direction

An English lifestyle shop for considered everyday objects. The first screen pairs a quiet green editorial panel with sunlit interior photography. Product photography, useful details and straightforward shopping actions carry the rest of the experience.

- Palette: near-white #FAFAF8, ink #202520, forest #465748, pale green #DCE4D6, sand #C7BDA9.
- Typography: locally hosted Manrope, generous editorial headings, readable 16px body text, tabular prices.
- Layout: restrained 1280px content width, spacious sections, four-column desktop and two-column mobile product grids, persistent URL filters, mobile filter sheet.
- Interaction: visible keyboard focus, semantic links and buttons, labeled icon buttons, explicit errors and retry, modest hover feedback respecting reduced motion.
- Checkout: one page, US delivery, integer-cent totals, obvious simulated-payment controls, durable order receipts.

Design references reviewed: Anthropic frontend-design SKILL.md and Vercel web-design-guidelines. No design file is required for this code-first demo.
