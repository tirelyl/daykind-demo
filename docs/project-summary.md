# Daykind 项目总结

更新日期：2026-10-12。

线上演示：[https://daykind-demo.onrender.com](https://daykind-demo.onrender.com)。

Daykind 是面向海外消费者的中英文生活方式商品选购 Demo，完成了“浏览 → 查找 → 加购 → 注册登录 → 模拟支付 → 查看订单”的完整流程。项目已部署上线，线上业务流程由项目负责人手动验证通过。

## 已完成内容

### 商品选购与展示

- 提供 30 件固定商品，覆盖家居、厨房和随身用品。
- 首页展示品牌、分类和精选商品；列表支持搜索、分类、价格筛选、排序和分页。
- 筛选条件保存在 URL 中，从详情返回列表时恢复浏览条件。
- 商品详情支持图片、描述、颜色规格、数量选择和加购；规格使用稳定 SKU。
- 覆盖加载、空结果、错误重试和商品不存在等状态。
- 商品接口由 MSW 和固定 fixtures 提供，图片与字体随站点部署，运行时不依赖第三方商品或素材 API。

### 账号、购物车与订单

- 使用 Supabase Auth 实现邮箱密码注册、登录、退出和会话恢复，演示配置支持注册后直接登录。
- 游客购物车保存在 localStorage；登录后合并到数据库，同 SKU 数量取较大值。
- 合并失败时保留游客购物车并允许重试；退出时清理当前用户缓存。
- 购物车支持修改数量、删除和撤销，登录后的购物车与订单持久化保存。
- 仅维护 `cart_items`、`orders`、`order_items` 三张业务表，全部启用 RLS；账号由内置 `auth.users` 管理。
- 订单保存商品、规格、价格和收货地址快照，支持订单列表、详情及刷新后恢复。

### 模拟结账与异常处理

- 校验收货地址，按整数分计算金额；运费为 $6.99，商品小计满 $75 免运费，税费为演示值 $0。
- 提供模拟支付成功和失败两种结果，页面明确标注 Mock，不收集银行卡信息。
- 成功支付移除本次购买的条目，失败支付保留购物车。
- 结账 Edge Function 验证登录身份、商品、SKU、数量和固定库存，并重新计算金额。
- 数据库事务复核购物车版本，原子写入订单和明细，保留后来加入的其他 SKU。
- 幂等键绑定用户及请求摘要，重复提交返回同一订单；响应丢失后可恢复待确认的结账尝试。

### 响应式与国际化

- 提供桌面和手机布局，包括移动端菜单、筛选抽屉和商品网格。
- 使用 i18next / react-i18next 支持英文、中文即时切换，刷新后保留语言选择。
- 翻译覆盖导航、商品、规格、筛选、表单提示、购物车、结账和订单状态。
- 商品搜索同时匹配中英文；金额和日期按语言格式化，币种保持 USD。
- 850px 以下的服务说明区已统一改为左对齐。

### 工程与部署

前端采用 React、TypeScript、Vite、TanStack Router / Query / Form、Tailwind CSS、shadcn/ui 和 Zod。商品接口使用 MSW；账号、购物车、订单和结账使用真实 Supabase Auth / Postgres / Edge Functions。

工程优先使用官方 CLI 初始化，保留文件路由生成机制，并交付依赖锁文件、环境变量示例、数据库 migrations、测试与部署文档。前端通过 Render Blueprint 部署为静态站点，配置了 SPA 路由回退和 MSW worker 响应头。

## 已知问题与当前边界

- **依赖警告**：TanStack 路由生成器存在依赖内部的循环引用警告；基线验收中不影响类型检查、路由生成和构建，依赖版本已锁定。
- **回归覆盖**：中英文切换后的表单状态、中文搜索及历史订单展示，尚未纳入完整的新增自动化回归。
- **交易范围**：支付和税费为模拟值，库存仅作固定值校验，不提供真实扣款、退款或库存扣减。
- **账号范围**：演示配置关闭邮箱确认，未接入邮件通知和找回密码。
- **运营范围**：暂无商品后台、优惠券、多币种、全球配送或真实税费计算。
- **部署维护**：使用免费额度，演示前需要检查 Supabase 项目状态和平台额度。未授权给 Render 的公开仓库连接方式需要手动触发后续部署。

## 主要取舍

| 选择                                      | 原因                                              | 对应边界                                                   |
| ----------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------- |
| TanStack Router SPA                       | 减少应用运行时配置，适合静态部署和演示            | 暂未提供 SSR 或商品页预渲染                                |
| Supabase Auth / Database / Edge Functions | 通过现成认证、RLS 和事务能力完成持久化业务        | 权限与结账逻辑依赖平台能力，需要维护 migrations 和函数部署 |
| MSW + 固定商品目录                        | 保证内容稳定、易于展示异常场景，减少外部 API 依赖 | 目录变更需要同步构建前端并部署结账函数，暂无商品管理后台   |
| 真实账号和订单，模拟支付                  | 优先完成购物闭环、数据隔离和异常恢复              | 不覆盖真实支付接入、资金处理和库存扣减                     |
| 中英文界面、USD、美国地址                 | 在有限范围内完成可演示的国际化体验                | 语言切换不改变币种、配送国家或税费规则                     |
| Render 静态站点和 Supabase 免费额度       | 控制演示成本，减少部署维护                        | 需要关注额度、项目状态及仓库自动部署授权                   |
